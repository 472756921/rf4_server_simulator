# 客户端兼容性检查清单

在数据库初始化完成、所有服务器进程就绪，并且客户端已配置为连接本地网关后，使用本清单进行检查。目标协议格式面向 RF4 客户端 **4.0.25034**。

## 登录与会话

- [ ] HTTPS 登录返回包含主机、端口、用户 ID 和 token 的 `<logon>` 响应。
- [ ] 客户端建立实时连接并收到初始推送。
- [ ] 客户端进入游戏世界，且没有反复尝试登录。
- [ ] 与 `gateway.region` 对应的客户端文本正确。
- [ ] 世界时钟按配置的 keepalive 间隔推进。

## 玩家状态

- [ ] 等级、经验、银币、金币和银行存款与数据库一致。
- [ ] 初始背包和快捷栏绑定可见。
- [ ] 技能面板列出所有已配置的技能分类。
- [ ] 移动到新地图后，保存的玩家位置会更新。

## 钓鱼

- [ ] 钓竿可以抛投，并返回有效的抛投距离、深度和鱼钩 ID。
- [ ] 正常咬钩会产生预期的浮漂动画和鱼讯信息。
- [ ] 刺鱼、溜鱼和收线可以完成，不会卡在钓鱼状态。
- [ ] 空竿抛投返回有效结果，并允许再次抛投。
- [ ] 渔获结算会更新经验、货币、统计数据和玩家 HUD。
- [ ] 钓到鱼后，鱼会加入鱼护。
- [ ] 放生鱼会获得配置的放生经验，并可触发升级。
- [ ] 拟饵和喂食器钓竿的行为遵循配置的装备与计时规则。
- [ ] 更换鱼饵会改变可钓到的鱼结果。
- [ ] 会话仍可恢复时，客户端重连后钓鱼状态可以恢复。

## 背包与装备

- [ ] 可以打开钓竿、渔轮、鱼饵、拟饵和配件的物品详情。
- [ ] 可以装配和卸下钓竿、渔轮、鱼线、鱼钩、浮漂和鱼饵部件。
- [ ] 部件耐久度和强度可见。
- [ ] 工坊修理会更新物品状态。
- [ ] 已丢弃物品的 GUID 不会被重复使用。
- [ ] 删除的物品会同时从背包和快捷栏中消失。

## 经济

- [ ] 商店打开后会显示其配置的目录。
- [ ] 购买会扣除正确货币并添加物品。
- [ ] 出售或退货操作会按正确货币扣款或入账。
- [ ] 商店覆盖配置会改变价格或库存，且不影响其他商店。
- [ ] 重复或重放的购买请求不会产生第二次扣款。

## 邮件

- [ ] 目标玩家可以收到文本邮件。
- [ ] 附件显示正确的物品和数量。
- [ ] 领取附件会更新背包和邮件状态。
- [ ] 已领取的邮件在重连后仍不会出现。

## 管理功能

- [ ] 刷新或重连后可以看到玩家编辑结果。
- [ ] 在线玩家会收到属性、技能、背包和鱼护更新。
- [ ] 下一次商店请求会使用商店覆盖配置。
- [ ] 钓鱼配置修改会影响下一次符合条件的抛投。
- [ ] 从控制台发送的邮件会投递到客户端。
- [ ] 踢下线只会断开目标玩家，不影响其他会话。
- [ ] 封禁会阻止目标玩家再次登录。
- [ ] 管理操作产生的变更会出现在审计日志中。

## 重连与稳定性

- [ ] 短暂网络中断后，会话会以连续的 RC4 流恢复。
- [ ] 网关重启后，客户端会重新连接，并在有可用保存交接状态时恢复。
- [ ] gameserver 重启会强制建立新会话，且不会让客户端停留在不完整的钓鱼状态。
- [ ] 长时间进行钓鱼和背包操作不会触发 keepalive 断线。
